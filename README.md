One line, 87 characters: the funniest error message a kitchen toaster would show its owner. The bread is jammed, the owner is shaking the appliance, and the toaster — deadpan, done with all of it — points out it is a toaster, not a vending machine.

> ERROR E04: Bread jammed. Please stop shaking me. I am a toaster, not a vending machine.

## Run it

```sh
python3 main.py --self-test
python3 main.py
```

`main.py` writes the entry to `/output/entry.txt` (override with `--output FILE`), validates it against the gate (1–120 characters, single line, not only white space), and reads it back to confirm the file holds exactly the entry. Standard library only, deterministic, no network, no clock.
